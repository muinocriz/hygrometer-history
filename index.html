月视图：半透明柱为当日最低～最高，折线为每小时最高 / 最低值；数据不足的日期不画柱子，以灰底标出。黄色窄框为参考气温（当日最低～最高）：优先使用你导入的气象站数据，其余日期使用 Open-Meteo 历史天气（ERA5 再分析格点模型数据，非站点实测，最近几天通常尚无数据），按页面顶部所选位置查询。日、年视图另含平均值，每小时平均值 = (该小时最低 + 最高) / 2。虚线表示缺失数据的区段，两端用实测值连接。

湿度舒适等级（按露点）

露点由每小时平均温度与平均湿度经 Magnus 公式计算（a = 17.62, b = 243.12℃）。每天各等级占比 = 该等级小时数 / 当天有效小时数。折线为“闷热及以上”（露点 ≥ 18℃）的占比。
